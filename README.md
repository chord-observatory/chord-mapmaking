# chord-mapmaking
Producing spatial maps from visibilities produced by CHORD

## Installation instructions

Run:

		git clone --recurse-submodules git@github.com:chord-observatory/chord-mapmaking.git

This will recursively install the radivs and radivs examples submodules. The submodules are specifically pointing to the release branches of those repositories which are safe to run.
